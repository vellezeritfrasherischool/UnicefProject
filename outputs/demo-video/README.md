# MësoLehtë school demo video

This directory contains the edited school-facing demo, Albanian narration assets, and the narration script.

The original screen recordings remain unchanged on the Desktop.

## Final deliverable

- `mesolehte-demo-shkolla-albanian.mp4`
- `mesolehte-demo-shkolla-albanian-english-subtitles.mp4` (English subtitle track included and enabled by default)
- `mesolehte-demo-english.srt` (standalone English subtitles)
- 1920×1080, H.264 video with AAC stereo audio
- Duration: 6 minutes 17 seconds

## Main behaviors shown

- Administrator login and creation of a teacher invitation
- Teacher registration with the unique invitation code
- Creation of a class and manual creation of a student account
- Upload of a PDF or text material and selection of AI adaptations
- Teacher review, approval, and publication of generated material
- Analytics, bonus stars, accessibility preferences, and notifications
- Student self-registration using a class code
- Student login using an account created manually by the teacher
- Reading, Albanian audio, quiz completion, and the generated report
- Student rewards, accessibility preferences, and notifications

The long report-generation wait is accelerated in the edit.
